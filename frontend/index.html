🎯 Sobre el Proyecto

PHP InsightLab ML Hub es una plataforma de Machine Learning desarrollada con PHP-ML, diseñada para demostrar capacidades de análisis avanzado con inteligencia artificial y procesamiento de datos.

Características Principales:
  • 🔤 Detección Automática de Idiomas
  • 🛡️ Filtrado Inteligente de Spam
  • 🍷 Predicción de Calidad del Vino
  • 📊 Clustering K-Means Interactivo
Tecnologías Utilizadas:
PHP PHP-ML JavaScript Tailwind CSS Chart.js Machine Learning
